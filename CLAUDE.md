# Claude project guidance

Follow [the project working agreement](AGENTS.md) and the adopted Constitution. Use the native installed Spec-Kit skills when selected; supplemental guidance does not replace their procedure or grant external permissions.

Keep questions concise, one consequential question at a time, with the actual question/options/recommendation visible in ordinary chat text even when using question cards. Preserve confirmation, safe handoff and synthetic/live distinctions. Report actual tests and blockers, not merely files created.
