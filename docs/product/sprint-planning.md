# Sprint planning

Status: a formal sprint and owner/date assignments are deferred. The selected work increment is the required scheduling slice in [spec](../../specs/001-appointment-scheduling/spec.md) and [plan](../../specs/001-appointment-scheduling/plan.md). Detailed work/dependencies will be generated by native Tasks; no implementation completion is recorded here.

- Goal and user outcome: not yet selected.
- Owner / participants: not yet assigned.
- Scope and source: link approved feature spec/plan and chosen [backlog](backlog.md) items.
- Acceptance/demo: link meaningful tests and the working [demo runbook](../internal/demo.md).
- Dependencies / decisions / risks: identify real blockers; do not invent approval gates.
- Work: link the feature's Spec-Kit `tasks.md`; update completion there, not here too.
- Review: record what worked, remaining limitations and the next useful increment in [next steps](next-steps.md).

Dates/effort estimates, when supplied, are planning advice—not agent stop conditions. Keep [roadmap](roadmap.md) direction aligned without adding ceremony.
